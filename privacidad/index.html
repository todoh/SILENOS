1. Resumen General

En SILENOS Browser Control nos tomamos la privacidad muy en serio. Esta extensión está diseñada para operar como un asistente de navegación web accionado por voz y visión. Toda la configuración clave se gestiona de forma local en tu dispositivo.

2. Datos Recopilados y Procesados

SILENOS no vende, no alquila ni rastrea la actividad del usuario fuera de las acciones estrictamente necesarias para el funcionamiento de la extensión:

  • Clave de API de Gemini (API Key): Se almacena exclusivamente en el almacenamiento local de tu navegador (chrome.storage.local). Nunca se transmite a servidores propios ni a terceros que no sean los endpoints oficiales de Google Gemini API.
  • Capturas de pantalla (Viewport) y Contenido de Páginas: Cuando utilizas comandos de voz o funciones analíticas, la extensión captura temporalmente el área visible del navegador o analiza el DOM para permitir al modelo de IA identificar elementos interactivos. Estos datos se procesan en tiempo real vía WebSocket hacia la API de Google Gemini y no se almacenan permanentemente.
  • Audio del Micrófono: Las señales de audio capturadas durante el uso activo del micrófono se transmiten en formato PCM a la API de Gemini para el reconocimiento e interpretación de comandos por voz.

3. Uso de Permisos del Navegador

  • storage: Guardar tu API Key en tu dispositivo.
  • activeTab / tabs: Interactuar con la pestaña actual que estás consultando.
  • scripting: Insertar etiquetas de identificación visual en elementos clicables para permitir un control de precisión por voz.
  • sidePanel: Desplegar la interfaz del asistente sin interrumpir tu navegación principal.

4. Transferencia a Terceros

No compartimos ni comercializamos datos personales ni de navegación con ninguna empresa publicitaria ni de analítica. El único intercambio de datos técnico ocurre de forma directa entre tu navegador y los servidores de Google Gemini API utilizando la API Key que tú proporcionas.

5. Contacto

Si tienes preguntas sobre esta Política de Privacidad, puedes ponerte en contacto a través de nuestro canal de soporte o repositorio oficial.

1. Overview

At SILENOS Browser Control, we prioritize your privacy. This extension is built as a voice and vision-driven web navigation assistant. All key configurations and settings are strictly managed locally on your device.

2. Data Collection and Processing

SILENOS does not sell, rent, or track user activity outside of the immediate functional requirements of the extension:

  • Gemini API Key: Stored exclusively in your browser local storage (chrome.storage.local). It is never sent to any external servers other than official Google Gemini API endpoints.
  • Viewport Captures & Web Content: When voice or visual features are activated, the extension temporarily captures the visible browser area or DOM structure to allow the AI model to identify interactive elements. This data is transmitted in real-time via WebSocket directly to Google Gemini API and is not retained permanently.
  • Microphone Audio: Audio streams captured while the microphone is enabled are converted to PCM format and transmitted to Google Gemini API for real-time voice command processing.

3. Extension Permissions

  • storage: Saves your API Key locally on your device.
  • activeTab / tabs: Interacts with the active browser tab you are currently viewing.
  • scripting: Injects visual tag markers over interactive elements for precision voice control.
  • sidePanel: Displays the assistant interface smoothly alongside your active browser tab.

4. Third-Party Sharing

We do not sell, transfer, or share any personal or browsing data with ad networks, data brokers, or analytics partners. All data exchanges occur strictly between your browser and Google Gemini API using your provided API Key.

5. Contact

For any questions or inquiries regarding this Privacy Policy, please contact us via our official support channel or repository.

1. 概述

在 SILENOS Browser Control，我们高度重视您的个人隐私。本扩展是一款基于语音与视觉驱动的网页浏览助手。所有核心配置与密钥均严格保存在您的本地设备中。

2. 数据收集与处理

SILENOS 不会出售、出租或跟踪用户在扩展核心功能之外的任何浏览活动：

  • Gemini API 密钥： 仅存储在您浏览器的本地存储中（chrome.storage.local）。绝不会发送至除 Google Gemini API 官方端点以外的任何第三方服务器。
  • 屏幕截图与网页内容： 当您激活语音或视觉分析功能时，扩展会临时捕获浏览器的当前可见区域或分析网页结构，以便 AI 模型识别可交互元素。此数据通过 WebSocket 实时传输至 Google Gemini API，不会进行永久存储。
  • 麦克风音频： 在开启麦克风期间采集的音频信号会转换为 PCM 格式并发送至 Google Gemini API，用于实时语音指令识别。

3. 扩展权限说明

  • storage：用于在本地安全保存您的 API 密钥。
  • activeTab / tabs：用于与您当前正在浏览的标签页进行交互。
  • scripting：用于在网页可点击元素上添加视觉编号标记，以实现高精度的语音控制。
  • sidePanel：用于在侧边栏平滑展示助手界面，不干扰主网页浏览。

4. 第三方共享

我们绝不会将任何用户数据或浏览记录出售或共享给广告网络或数据分析公司。所有技术数据交换仅在您的浏览器与 Google Gemini API 之间直接进行。

5. 联系方式

如果您对本隐私政策有任何疑问，请通过官方支持渠道或代码仓库与我们联系。
